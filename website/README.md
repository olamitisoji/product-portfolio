# Personal website

The static site in `dist/` contains my selected work, experience and writing. [Visit my personal website](https://soji-agboola-portfolio.boileditem.chatgpt.site/)

## Local preview

From the repository root, run this command and open [the local site](http://127.0.0.1:3010/).

```sh
python3 -m http.server 3010 --bind 127.0.0.1 --directory website/dist
```

The homepage is in [dist/index.html](dist/index.html). Individual case studies are in [dist/work](dist/work).
